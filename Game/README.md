This Folder contains the actual playable game used for the advanced tasks.

To run the game, first navigate to this folder in the terminal and run the following command:

```!python TheBindingOfRL-QLearning.py```


The Game is played as follows:

Use the W, A, S, D key to move Up, Left, Down, Right movement respectively.

Use the ←, →, ↑, ↓ keys to shoot Left, Right, Up, Down respectively.

Defeat all the enemies before the time runs out or the player sustains damage from the enemies.
